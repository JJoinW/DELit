# DELit
Source code and data of our EMNLP 2026 Findings paper From Benchmarking to Failure Diagnosis: Diagnosing Classical Chinese Understanding in LLMs via IRT and Error Attribution.

## Acknowledgements
This project uses the raw data from the following work.

Dongning Rao, Rongchu Zhou, Peng Chen, and Zhihua Jiang. 2025. A comprehensive literary chinese reading comprehension dataset with an evidence curation based solution. In Proceedings of the 2025 Conference on Empirical Methods in Natural Language Processing, pages 3583–3603.
